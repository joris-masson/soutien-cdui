# Introduction
Le fameux F12 que vous pouvez lancer dans la plupart des navigateurs, ou alors un petit clic droit puis "inspecter l'élément".
Avec ce petit machin, on peut faire des merveilles.

J'en parle rapidement dans la note [[JavaScript]] avec [[JavaScript#La console|la console]], mais d'autres trucs existent.

Je ne vais détailler que ce qui pourrait vous servir à vous.
# Inspecteur
C'est la partie principale, ici vous pouvez voir tout le HTML tel qu'il est actuellement, il est mis à jour en tant réel et vous pouvez également le modifier.
Généralement, vous avez les règles CSS juste à côté, que vous pouvez aussi modifier en temps réel, pratique pour faire des ajustements ou vérifier pourquoi un truc ne marche pas.

# Vue adaptative
Giga cool lorsque vous devez travailler la responsive. Vous pouvez afficher votre page, dans votre navigateur, comme si elle était rendue sur un mobile.
Il est possible de modifier à volonté les dimensions en pixels de votre rendu.

Vous pouvez l'activer avec CTRL+Shift+M sur Firefox.
# Lighthouse
C'est le plus surprenant je dirais.
Il n'est disponible que sur Google Chrome (peut-être aussi les autres navigateurs basés sur Chromium, je n'ai pas vérifié).

Cet outil permet de lancer toute une analyse de votre site web, et va vous générer un rapport avec une note.
Certains sites proposent cet outil en ligne également.

Ce qui est analysé, c'est le temps de chargement de votre page notamment, et de tous ses éléments, ainsi que l'accessibilité et les bonnes pratique de SEO.
Vous pouvez lancer une analyse en mode desktop ou mobile.
