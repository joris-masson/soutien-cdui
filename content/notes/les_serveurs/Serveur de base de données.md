# Introduction
C'est là que se situe votre base de données.
Généralement, le serveur de base de données **est** le SGBD. Donc MySQL ou MariaDB par exemple.
Vous ne devriez pas avoir besoin de manipuler ce serveur normalement.
# Sécurité
Un serveur de base de données ne doit **JAMAIS** être directement exposé sur internet.
À comprendre là que personne d'autre que votre serveur web et vous-même ne devriez y avoir accès.
