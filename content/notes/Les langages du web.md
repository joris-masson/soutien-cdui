# Introduction
Ce qu'on appelle langages du web, ce sont tout simplement les quelques langages principalement utilisés sur le web, il y en a principalement 4 :
- [[HTML]]
- [[CSS]]
- [[JavaScript]]
- [[notes/les_langages_du_web/PHP|PHP]]
Nous pouvons aussi rajouter [[notes/les_langages_du_web/SQL|SQL]], qui n'est pas vraiment un langage du web, mais en est indissociable pour autant.
Cette note va servir à parcourir ces différents langages, et à expliciter leurs usages principaux.

Les différentes notes abordent les **bases** de ces langages, mais d'un point de vue un peu technique quand-même, pour essayer de réussir à comprendre pourquoi les choses marchent de telle ou telle façon.
Il est possible que vous soyez à l'aise avec la plupart des trucs abordés ici, auquel cas, enjoy le mansplaining qui va suivre. 🫡
